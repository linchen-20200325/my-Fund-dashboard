# 除息/配息行事曆 — 說明(v19.537)

你的基金**除息基準日 + 配息入帳日**推估月曆。對象 = 追蹤清單 ∪ 持倉,**加減基金 → 下月自動更新**。
看的是哪個月分兩路:**App 內看「本月」**(方式 A,隨時開隨時算);
**LINE 推播每月 28 號推「下個月」**(方式 C,月底先知道下個月哪天除息、大概哪天到帳)。

> ⚠️ **日期是推估,不是官方公告**:用各基金過往配息節奏推算(月配節奏穩才可靠,帶信心度)。
> 配息入帳日為除息日後一個月內,實際依基金公司作業;除息日以**基金公司網站公告**為準。
> 累積型 / 無配息的基金自動不列(不是漏抓)。

---

## 方式 A — App 內即時月曆(隨時看)
**我的管理室 → 🗓️ 除息行事曆**。用你**已載入**的持倉基金(含配息史)即時算本月月曆 + 可下載 HTML。
- 沒東西?先到 **Tab④ / 組合健診**載入基金,再回來看。
- 視覺完整(月曆格子 + 明細 + 信心度 + 排除區),深/淺色皆適配。

## 方式 C — 每月月底 LINE 摘要(提醒下個月)
`scripts/dividend_calendar_notify.py` + `.github/workflows/dividend_calendar_notify.yml`:
每月 **28 號 08:23 台灣** 對持倉∪追蹤清單推估**下個月** → 推一則 LINE(「10/7 摩根 JFZN3 除息…」)。

> **為什麼是 28 號 08:23**(v19.537,兩個理由都別再改回去):
> - **28 號**:2 月沒有 29~31 號,固定 28 號才保證**每月都觸發恰好一次**,不必寫「是不是當月最後一天」的判斷。
> - **08:23 而非 08:00**:GitHub 排程在**整點**為高負載時段,會延遲甚至直接丟棄 job
>   (本 repo 實測整點的另一條 workflow,13 次觸發**沒有一次**在 62 分鐘內起跑,最長 693 分鐘)。
>
> ⚠️ **「28 號」與「推下個月」是一組配對**:只准「月底發下個月」或「月初發本月」,
> **不可**變成「月初發下個月」(user 2026-09-01 裁示)。cron 與 `main()` 目標月改一邊就要改另一邊
> —— 2026-08-24 只改目標月沒改 cron,結果 2026 年 9 月的行事曆從未被自動送出。
> `tests/test_dividend_calendar_cron_v19537.py` 鎖住 cron 字面值,漂移即紅燈。

**用的 secret 和「換股顧問健康週報」完全一樣**(不用另設):
`GOOGLE_SERVICE_ACCOUNT`(讀持倉,可缺→只跑追蹤清單)、`MACRO_WEIGHTS_SHEET_ID`、
`WATCH_CSV_URL`(追蹤清單)、`LINE_CHANNEL_TOKEN` **或** `LINE_CHANNEL_ACCESS_TOKEN`、`LINE_USER_ID`、
`PROXY_URL`(選填,美國 IP 抓 MoneyDJ)。

**驗證 / 補送某個月**:Actions →「除息行事曆 月底摘要 (LINE)」→ Run workflow →
`dry_run=true` 看 log → 再 `false` 實送一則。排程實送、手動 dry_run 先驗。
- **`target_month`**(選填):填 `YYYY-MM`(例 `2026-09`)= 補送**指定月份**;**留空 = 下個月**(排程行為)。
  格式打錯(`2026-13` / `202609` / 亂填)→ **直接報錯離開、不送**,不會靜默退回下個月(§1:
  寧可沒送,也不讓你以為補送成功卻收到別的月份)。
  本機同義:`python scripts/dividend_calendar_notify.py --dry-run --target-month 2026-09`。
- 補送不影響「陳舊度」判讀:程式量測基準恆為**執行當下**,不會跟著 `target_month` 跑。

## 推估方法(§7,透明)
- **判頻率**:相鄰除息日間隔中位數 → 月配(≈30)/季配(≈90)/年配(≈365)。
- **推除息日**:月配 → 近幾筆除息日「幾號」中位數 = 每月固定除息日 → 套**目標月**(超月底取月底)。
- **推入帳日**:除息日 + 歷史「除息→發放」間隔中位數(缺 pay_date → 留白,不硬編)。
- **信心度**:筆數 + 「幾號」離散度;少筆/離散大 → 標「低」,不硬給精準日(§1)。
- **季/年配**:上次除息 + 週期恰落**目標月**才列,否則該月不顯示(誠實)。

模組:`services/dividend_calendar.py`(L2 純邏輯)、`ui/helpers/dividend_calendar_render.py`(HTML)。
