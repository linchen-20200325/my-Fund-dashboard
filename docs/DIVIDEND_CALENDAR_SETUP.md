# 除息/配息行事曆 — 說明(v19.443)

你的基金**本月除息日 + 配息入帳日**推估月曆。對象 = 追蹤清單 ∪ 持倉,**加減基金 → 下月自動更新**。

> ⚠️ **日期是推估,不是官方公告**:用各基金過往配息節奏推算(月配節奏穩才可靠,帶信心度)。
> 配息入帳日為除息日後一個月內,實際依基金公司作業;除息日以**基金公司網站公告**為準。
> 累積型 / 無配息的基金自動不列(不是漏抓)。

---

## 方式 A — App 內即時月曆(隨時看)
**我的管理室 → 🗓️ 除息行事曆**。用你**已載入**的持倉基金(含配息史)即時算本月月曆 + 可下載 HTML。
- 沒東西?先到 **Tab④ / 組合健診**載入基金,再回來看。
- 視覺完整(月曆格子 + 明細 + 信心度 + 排除區),深/淺色皆適配。

## 方式 C — 每月月初 LINE 文字摘要(提醒)
`scripts/dividend_calendar_notify.py` + `.github/workflows/dividend_calendar_notify.yml`:
每月 **1 號 08:00 台灣** 對持倉∪追蹤清單推估 → 推一則 LINE(「8/7 摩根 JFZN3 除息…」)。

**用的 secret 和「換股顧問健康週報」完全一樣**(不用另設):
`GOOGLE_SERVICE_ACCOUNT`(讀持倉,可缺→只跑追蹤清單)、`MACRO_WEIGHTS_SHEET_ID`、
`WATCH_CSV_URL`(追蹤清單)、`LINE_CHANNEL_TOKEN` **或** `LINE_CHANNEL_ACCESS_TOKEN`、`LINE_USER_ID`、
`PROXY_URL`(選填,美國 IP 抓 MoneyDJ)。

**驗證**:Actions →「除息行事曆 月初摘要 (LINE)」→ Run workflow → `dry_run=true` 看 log →
再 `false` 實送一則。排程實送、手動 dry_run 先驗。

## 推估方法(§7,透明)
- **判頻率**:相鄰除息日間隔中位數 → 月配(≈30)/季配(≈90)/年配(≈365)。
- **推除息日**:月配 → 近幾筆除息日「幾號」中位數 = 每月固定除息日 → 套本月(超月底取月底)。
- **推入帳日**:除息日 + 歷史「除息→發放」間隔中位數(缺 pay_date → 留白,不硬編)。
- **信心度**:筆數 + 「幾號」離散度;少筆/離散大 → 標「低」,不硬給精準日(§1)。
- **季/年配**:上次除息 + 週期恰落本月才列,否則本月不顯示(誠實)。

模組:`services/dividend_calendar.py`(L2 純邏輯)、`ui/helpers/dividend_calendar_render.py`(HTML)。
