## 三、相容性判斷（INFERENCE，不是已確認）

- **移除鍵（`verdict.action`、`action_light` 整塊、`regime.alloc_suggest`）會改變已出現在工具說明與回傳 dict 的輸出契約**；因為 U1／U2 無法排除，**不能說「安全」**。
- **置 null 保鍵**對 schema 破壞較小，但仍改變語意（下游可能把 null 當資料缺），且客戶本次方向是「未確認前不直接刪除已公開輸出欄位」——**置 null 在本批也未被授權，視同改輸出，不做**。
- **repo 內自家相容面**：移除鍵會使 `tests/test_mcp_server_smoke.py` 紅（C6）；這是內部相容成本，可由同批改測試處理，但**不能**證明外部相容。
