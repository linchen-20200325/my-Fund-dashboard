# New UI2 深色／淺色切換：後續需求登記（2026-11-11）

> **性質**：客戶需求要點的 docs-only 登記草案，供正式 DEC／BACKLOG／HANDOFF 收斂；非施工授權、非已核准之 UI 設計 SSOT。本文件在 PR 合併前不代表 main 的正式決策。來源：客戶在 ChatGPT 對話詢問雙模式切換後，於提出「下一階段正式需求」時回覆「好 那請繼續」（要點轉述，無逐字對話存檔）；若後續裁示不同，以客戶最新裁示為準。

## 需求及邊界

- **需求**：基金 New UI2 未來應支援使用者手動切換 **☀️ 淺色／🌙 深色**。建議切換入口在 ⚙️ 設定，能記住使用者選擇。預設為目前已核准的淺色主內容＋深色側欄。
- **時序**：目前已裁示的 G3（B 色票＋A 尺寸）／G6（限縮 UI 容器與 Secondary 頂對齊）是**獨立在先的施工批**。不要在該批進行中擴大施工範圍；雙模式獨立做下一階段設計／技術驗證與 Decision Gate。
- **深色值**：暫無獲核准的 dark token／實測對比／正式切換實作；不得直接將 `.streamlit/config.toml` 換成 dark，或把 G3 的 B 色票誤認為深色主內容模式。
- **儲存策略**：偏好可持續記住選擇，但是否採 Streamlit session、瀏覽器儲存、設定檔或其他方式，以及跨裝置／登入／Active Sheet 的語意尚待技術盤點與客戶裁示；不得假設保存能力或偷偷新增雲端寫入。
- **驗收條件（待細化）**：兩模式都要維持字色／狀態色／邊線之對比與文字＋符號提示；390／768／1280 無橫溢、切換可用、首屏預算不變、資料顯示與金融語意一致；須各有瀏覽器級證據並計畫真機／Cloud 驗證。缺資料不可用 0、neutral 或 safe 取代。
- **硬邊界**：不改基金 IA、金融公式、`STATUS_TONES` 映射、FRED、資料契約、FX Gate、OneBrain、`ui_v2` 或正式入口；BL-0545 的唯一 NEXT 不變。

## 下一階段候選方案（三選一，非施工）

| 方案 | 範圍 | 正確性／風險 | 速度／Token |
|---|---|---|---|
| A 固定淺色 | 不提供切換 | 最低風險，但不滿足新需求 | 最快／最低 |
| **B 手動切換（推薦）** | 淺色預設；設定頁日／夜切換；適當保存選擇 | 中風險，需原生 Streamlit／自繪 HTML 協調與無障礙驗收 | 中／中 |
