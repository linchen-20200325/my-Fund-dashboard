## §1 在 Streamlit Cloud 建預覽 app

1. 在 Streamlit Cloud 新增一個 app，指向本 repo，主程式檔填 **`ui_v2/app_preview.py`**。
   - ⚠️ Streamlit Cloud 介面上的按鈕名稱與步驟，本組沒有實際操作，未查證；以當時的介面為準。

2. 套件依 repo 根目錄的 `requirements.txt`（其中 streamlit 的宣告，2026-10-16 讀到的是 `>=1.59.1,<1.60.0`；此值會漂移，驗收時請現場讀該檔）。Streamlit Cloud 選用的 Python 版本，本組未查證。

## §3 各試算表需要的分頁

**設定試算表**（`repositories/settings_sheet_repository.py` 的 `TAB_*` 常數）：

| 分頁名 | 誰讀／誰寫 |
|---|---|
| `user_setting_log` | 各頁已存設定的讀取來源；存檔時追加一列 |
| `market_indicator` | 市場總覽的落地值；設定與診斷、資產配置讀；「重新取數」寫入 |
| `fetch_log` | 設定與診斷讀取取數紀錄；「重新取數」寫入 |
| `fetch_log_open` | 同上（未結束的取數紀錄） |

- 分頁不存在時，第一次寫入會自動建立並寫一次標頭；已有資料但標頭與規格不符時**停下不改寫**，畫面照實顯示失敗（`repositories/settings_sheet_repository.py::_worksheet_for_append`、`_check_header`）。
- 讀取時分頁不存在的畫面表現，本組沒有逐頁查證。

**保單試算表**（`repositories/policy_supplement_repository.py`）：

- `_持倉補充`、`_保單資料` 兩個補充分頁（`TAB_HOLDING_SUPPLEMENT`、`TAB_POLICY_PROFILE`）。
- 各保單分頁：名稱不以 `_` 開頭、且不是 `Policies` 的分頁，會被當成保單分頁逐一讀（`_list_policy_tabs`）。

**選股池試算表**：分頁 `_fund_pool`，標的探索只讀它的**代碼欄**（`repositories/pool_repository.py::_WS_POOL`；`ui_v2/app_preview.py` 檔頭）。沒有服務帳戶時不讀本機暫存檔，畫面寫「選股池未設定雲端來源」。
