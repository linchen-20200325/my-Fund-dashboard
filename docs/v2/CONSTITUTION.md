##### ⛔ §6.2.5-E1 收窄：E1 必須**逐子句**判定，不得整句套用

> **有意識的政策變更，不是漏刪** · 日期 **2026-09-14** · 決策者：**AI 總管**（第二輪回修組執行）

**E1 原本要豁免的是「降低行動性的話」，結果豁免了兩句叫人進場的話。**

**⇒ 現行 E1 條文（取代舊表述的判定方式，豁免對象本身不變）**：

> **E1 逐子句判定：**
> 1. **以子句為單位**（中文逗號／頓號／分號／冒號切分），**不是以整句為單位**。
> 2. **同句中只要有任一子句是「肯定式部位動作」，整句即不得豁免** ——
>    即使其他子句是否定形。
> 3. **豁免只及於該否定子句本身**，⛔ 不得外溢到同句的其他子句。
> 4. **形式否定但語意為指令者不得豁免**：「**不**要錯過這一波」「**別**再等了」
>    —— 它們含否定詞，但**提高**而非降低行動性。**E1 看的是行動性，不是有沒有「不」字。**

**逐子句重測那五句 → 0/5 可被 E1 豁免。** ✅（五句全部至少有一個肯定式部位動作子句。）

##### ⛔ §6.5-P precedence 的例外：守衛**不得**凌駕母法

> **有意識的更正，不是漏刪** · 日期 **2026-09-14** · 決策者：**AI 總管**（第二輪回修組執行）

### §7.5 遮蔽規則（Masking）

#### §7.5.1 規則 1：API 金鑰 —— **沿用既有實作，不要另寫**

`ui/tab5_data_guard.py::_mask_key`（本組逐字讀出）：

```
if not val:  return "(空)"
n = len(s)
if n <= 8:   return f'{"*" * n} (len={n})'
return f"{s[:4]}…{s[-4:]} (len={n})"
```

**本組以合成探針 runtime 驗證（⛔ 未使用任何真實金鑰）**：

| 輸入長度 | 輸出 |
|---|---|
| 0 | `(空)` |
| 2 | `** (len=2)` |
| 8 | `******** (len=8)` |
| 9 | `ABCD…2345 (len=9)` |
| 39 | `AAAA…AAAA (len=39)` |

> ✅ **「查了但沒問題」也要寫下來**（`CLAUDE.md §2.1` 的同一把尺往內用）：
> **短字串邊界處理正確** —— `n <= 8` 時全部星號，**不會**因為
> `s[:4] + s[-4:]` 而把整個 8 字元的 key 原樣印出來。這是一個常見陷阱，**此處沒踩**。
>
> ⚠️ **但有一個誠實的殘留**：`n = 9` 時輸出 `ABCD…2345`，**9 個字元露出 8 個**。
> 對 9~12 字元的短憑證，此遮蔽**實質無效**。
> **v2 規則**：`n < 16` 一律全星號。⚠️ 這是本組的建議，**不是既有行為**。
