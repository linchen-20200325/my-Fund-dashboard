## 0. 怎麼讀

| 記法 | 意思 |
|---|---|
| `‹0.0›`、`‹n›`、`‹MM-DD›` | **格式遮罩（示意，非真實資料）** —— 只表示位數與單位寫法，不是觀測值 |
| `‹基金名稱 A›`、`‹類別 A›` | 示意佔位，非真實標的 |
| ［按鈕］ | 按鈕；類別照 44 第 5.3 節八類（取數／套用／展開／匯出／新增列／清除／導覽／存檔），本檔不新增第九類 |
| 依待裁示 (n) | 該元素取決於 58 第 13 節第 n 題，客戶未核准前不成立 |
| 〔本組擬定〕 | 44 沒有逐字規定、由本組擬的字樣，等客戶定 |

- 框寬約 40 欄（等寬字型，全形字算 2 欄）。符號在不同字型可能多佔或少佔一欄，右框線偶有不齊屬正常。
- **本檔沒有任何方向詞**：不出現該往哪邊動的字樣、目標價、配置答案、預期報酬、0～100 總分或信心百分比（44 第 1.2 節、58 U-25）。
- 狀態符號依 58 U-20 的**提案**：資料狀態 ✓ ◷ ◇ ⛔；評估狀態 ○ ◆ ⬜（**依待裁示 (2)(3)，客戶未核准**）。⛔ 這不是現行規格：核准前 44 現行規則照舊有效（`⬜` 資料未備與不適用、`⚠` 黃燈、`⛔` 取數失敗）；本檔框內出現的 ✓◷◇○◆ 一律是提案示意。
- 一般畫面不出現塊代號、「層 1～4」字樣、原始欄位鍵、試算表 ID（**依待裁示 (1)**）；它們移到 SET「進階診斷」。
- 四段 ①結論 ②關鍵數字 ③需要注意 ④詳細資料，③ 預設展開（**依待裁示 (7)**）。

## 1. 全站共用元素

### 1.1 全站情境列（每頁頁名下方一行）〔本組擬定〕

```text
┌──────────────────────────────────────┐
│ 組合：‹組合名稱›｜資料截至 ‹MM-DD›   │
│ 資料狀態：◷ 部分延遲                 │
│                     ［查看資料狀態］ │
└──────────────────────────────────────┘
```

- 「資料狀態」一律是最小狀態；完整診斷只在 SET（**依待裁示 (1)**）。［查看資料狀態］屬「導覽」類，導向 SET。
- 同源錯誤在一頁只出現在這一行與 ① 結論各一次；其他受影響區塊只寫「此區塊暫時無法判定」。

### 1.2 頁尾（五頁相同）

```text
┌──────────────────────────────────────┐
│ 本系統僅供數據分析與量化輔助參考，   │
│ 不構成任何形式之投資建議與買賣邀約   │
└──────────────────────────────────────┘
```

- 字句照抄子法 1 §6.1（客戶逐字定死，⛔ 照抄不得改寫）；框內折行只是版面，字句一字未改。
- ⚠️ B 線五頁現況沒有這一句；是缺口還是待裁示，見 `docs/BACKLOG.md` BL-0364，**本檔畫出來供客戶確認，不代表已判定**。

### 1.3 四態的共用寫法

| 狀態 | 寫法 | 和別的狀態怎麼分 |
|---|---|---|
| 載入中 | 「… 取得中」，已取得的區塊先顯示 | 不用灰框、不用 ⬜ |
| 空的 | 「⬜ 無法判定（尚未建立任何持倉）」之類，附導覽 | 說的是「沒有東西」 |
| 尚未設定 | 「⬜ 無法判定（規則未設定）」或「尚未設定條件」，附該頁主要按鈕 | 說的是「你還沒設」 |
| 錯誤 | 「⛔ ‹哪一類› 取數失敗」，附［查看資料狀態］；原文只在 SET 進階診斷 | 文字只描述狀態，不指示動作（客戶 2026-10-03 裁示）|
