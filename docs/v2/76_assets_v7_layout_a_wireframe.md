## 2. A 的意圖與邊界（引用客戶，不複製全文）

- 頁級容器留在第一眼位置，**取代**兩枚燈的重複 presentation；兩枚燈在這一頁不再畫。
- **只是 presentation de-duplication**：`HLD-0`／`ALO-0` 兩個 domain block 的身分、`_page_class`、`_state`、`_tone`、原始 rule result、reason、provenance、Digest mapping、決定性語意一個都不動。正式原則：**Domain Block Identity ≠ Presentation Instance**。
- 單獨 HLD／ALO 頁（`ui_v2/hld/page.py::render`、`ui_v2/alo/page.py::render`）與其他正式 consumer 的行為不得被破壞。
- 區段內原本只存在於燈下的功能與證據，逐項盤點、保留；搬不進容器的，在原區段留「功能／證據入口」，但不再重複完整狀態句。
