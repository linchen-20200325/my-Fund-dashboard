- `diff` 原檔 vs 存檔 → 唯一輸出為 `1552d1551` 與一個**空行** —— **刪掉的是一個空行，沒有第二處差異**

- 移除的 byte 逐字為 `b'\n'`，**移除數量恰為 1**
