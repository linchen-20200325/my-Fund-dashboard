## 1. 全站共用規則

### 1.1 什麼叫「一項」（頁首與總表共用同一個算法）〔U9〕〔新設計·F〕

- **一項＝一個原因**：
  - 尚未設定：以「哪一個設定」為一項（例：資料來源的金鑰、設定試算表 → 2 項）。
  - 取數失敗：以「哪一類資料」為一項（例：市場指標取數失敗 → 1 項，不論幾張卡受影響）。
  - 資料未備：以「哪一類資料」為一項。
  - 不是最新：整頁只算一項。
- 同一個原因影響幾張卡，都只算一項。
- **頁首「另有」＝這一頁的全部項數，扣掉主要原因那一項**；**總表「狀態」欄＝全部項數（含主要原因）**，依種類分開寫。兩者對同一個情境一定對得上。
- 「尚未設定」和「取數失敗」**永遠分開數**，即使兩者在卡上都是 ⛔。

### 1.2 頁首「主要原因」一行 〔U9〕＋挑選順序〔新設計·A〕＋「另有」行〔新設計·F〕

**現況**（市場總覽，模擬情境「尚未設定」：資料來源的金鑰與設定試算表都沒設，另外波動度指數真的取數失敗）：

```text
┌──────────────────────────────────────┐
│ 市場總覽                             │
│ 現在的市場環境，和我上次看的時候比， │
│ 變了哪裡                             │
│ 資料狀態： ◇ 資料未備　⛔ 取數失敗： │
│ 資料　尚未設定：資料來源的金鑰、設定 │
│ 試算表 · 資料截至 —                  │
│ 完整資料狀態在「設定與診斷」頁       │
└──────────────────────────────────────┘
```

問題：一行裡三種狀態，看不出先處理哪一個；「取數失敗：資料」說不出哪一類；同一件事在 ①、③ 又各講一次。

**提案**（同一情境）：

```text
┌──────────────────────────────────────┐
│ 市場總覽                             │
│ 現在的市場環境，和我上次看的時候比， │
│ 變了哪裡                             │
│ ⛔ 主要原因：資料來源的金鑰尚未設定  │
│ 　（2 張卡有值讀不到）               │
│ 另有：尚未設定 1 項　⛔ 取數失敗 1 項│
│ 　◇ 資料未備 1 項                    │
│ 資料截至 —　　　［前往設定與診斷］   │
└──────────────────────────────────────┘
```

- 為什麼主要原因是「金鑰」不是「設定試算表」：金鑰沒設讓風險情緒卡與資金與匯率卡的**主值讀不到**；設定試算表沒設只讓三張卡的**比較值**變成 ⬜ 不適用，主值照樣看得到。
- 「另有」裡的 3 項分別是：尚未設定（設定試算表）、取數失敗（市場指標：波動度指數）、資料未備（市場指標：領先指標等）。

**怎麼挑出唯一一條**〔新設計·A〕（第一個成立的就是主要原因）：

| 順位 | 情形 | 寫法 |
|---|---|---|
| 1 | 整頁載不出來 | `⛔ 本頁暫時無法判定：‹資料類›取數失敗`（現況照舊） |
| 2 | **尚未設定**，而且因此有主值讀不到 | `⛔ 主要原因：‹哪一項›尚未設定（‹N› 張卡有值讀不到）` |
| 3 | **取數失敗**（含「改用 ‹日期› 的預存淨值」） | `⛔ 主要原因：‹資料類›取數失敗（‹N› 張卡有值讀不到）` |
| 4 | 資料未備 | `◇ 主要原因：‹資料類›資料未備（‹N› 張卡有值讀不到）` |
| 5 | 不是最新 | `◷ 主要原因：部分只顯示最後有效資料` |
| 6 | 尚未設定，但只造成比較值 ⬜ 不適用 | 有其他問題時不當主要原因，只進「另有」；**整頁只有這一種問題時**，頁首不寫「主要原因」，只寫一行「尚未設定：‹哪一項›（只影響比較值）　資料截至 ‹日期›　［前往設定與診斷］」，不加符號 |
| — | 都沒有 | 不寫主要原因，只寫「資料截至 ‹日期›」（不寫「正常」） |

同順位比：(a) 讓比較多張核心卡有值讀不到的；(b) 影響結論燈的；(c) 該頁固定的資料類順序。

- **尚未設定排在取數失敗前**：沒設定的東西是其他東西的前提；設定與診斷的燈已經是這個順序。
- **G3**：一行只講一個原因；排第二的不消失——在「另有」裡，卡上照樣是 ⛔。
- **「尚未設定」加不加 ⛔——統一規則**（U9 要您確認的事）：
  - **主要原因那一行**：尚未設定讓主值讀不到時加 ⛔（跟卡上一致）；只造成比較值 ⬜ 時不加（見第 6 順位）。
  - **「另有」行與總表件數**：「尚未設定 N 項」**一律不加符號**——因為合計裡可能同時有「讓數字讀不到的」和「只影響比較值的」，用一個 ⛔ 會誇大後者。取數失敗、資料未備、不是最新照舊帶各自符號。（這與畫面規格現行頁首的寫法一致：現行頁首的「尚未設定」本來就不帶符號。）
  - 卡上與收合標題：照舊 ⛔ 尚未設定：‹哪一項›。
  - 現況頁首的「尚未設定」沒有符號，所以這一條只改主要原因那一行。

### 4.6 不再畫永遠按不了的按鈕 〔U4〕

**現況**（讀程式的結果）：標的探索在預覽站**沒有永遠按不了的按鈕**。會依情況停用的有：「加入觀察清單」（一檔都沒選時）、「存檔」「新增條件」（已存設定讀不到時）、對照第 4 檔（上限）。

**替代**：若 U4 的本意是依情況停用的也不畫，上列三種改成只寫原因句、不畫按鈕。不推薦（隱藏會讓人以為這個動作不存在）。
