## 3. 核心原則

**U-03 Exception First** —— 先列需要注意的項目，正常的收合成一行計數。MUST NOT 依偏離大小排出先後順序（44 塊 `HLD-1`「列不排序成優先順序」與 44 第 1.2 節「禁排名」）。【相容】

**U-04 Change First（有比較資料才做）** —— 有比較基準（觀察窗起點、上次已存值）才顯示「變了什麼」。沒有基準時照 44 塊 `MKT-4` 逐字寫「⬜ 不適用：尚未設定觀察窗」，MUST NOT 自己挑一個基準。「重大變化」要有規則才判；規則未設定時只列差值，不判大小。【相容】

**U-05 一頁（或一個設定群）最多一個主要按鈕** —— 其餘降為次要或收進展開區；同源失敗不在每張卡各掛一顆「重新取數」。【需解凍 44】（44 第 5.1、5.5 節要求失敗卡掛「重新取數」）

**U-06 Progressive Disclosure** —— 由上而下：結論 → 關鍵證據 → 原因與影響 → 來源、取得時間與診斷。展開區不自動打開（44 第 5.4 節）。【相容】
